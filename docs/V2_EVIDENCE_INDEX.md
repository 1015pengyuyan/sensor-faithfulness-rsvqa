# Evidence precedence and limits

| Evidence layer | Public attachment location | Interpretation |
|---|---|---|
| Original eight-model main matrix | `main/`, `analysis/original/` | Unified original prompt, 128 tokens; all eight retained |
| Dated inclusion supplement | `docs/V2_SCIENTIFIC_INCLUSION_POLICY.md` | Uniform scientific policy; not a rewrite of old technical admission |
| Post-hoc robustness | `robustness/` | All 32 model/dataset/sensor primary contrasts; limited extreme-tail precision |
| Corrected BEN collection | `position/`, `position_analysis/` | Original failures and independent supplemental receipts are distinct |
| Final position qualification | `position_closeout/` | Takes precedence over initial reuse-identity classifications |
| Quantitative figures | `figures/` | Complete model displays; no dataset-image redistribution |

Qwen3B's initially empty adapter field was not proof of an adapter mismatch.
Final closeout authenticates preserved native adapter/runner layers and separates
the newer wrapper identity; its cross-run use remains supplementary. A 20-call
bridge does not establish whole-population deterministic stability. Mantis has
the same bridge-scope limitation. LLaVA bridge evidence is not archived/authenticated
for paired position inference; this is not proof a bridge never ran.

Four complete same-round paired-position models are the core position evidence.
On the Qwen7 SAR common set (73 question–sensor units, 69 sources; 71 gold-no,
2 gold-yes), lower retention primarily corresponds to increased abstention,
not an equally large increase in reverse answers. Absolute rates are from the
same common set as the direct slot difference. Qwen3's small-sample empirical
zero-width intervals do not identify a precisely zero population effect.

Capability-conditioned D, fixed-population capability and model-specific CIFR/RSR
have different target populations. JSON/recovered describe format; abstain describes
answer category. Those dimensions cannot be added as mutually exclusive outcomes.
The frozen `strict_json_valid` flag follows the saved parser, which can recognize
a valid answer object embedded in surrounding text; it is not a new whole-response
JSON validator. We preserve the historical flag name and values.

No universal sensor superiority, internal attention mechanism, strict conditional
faithfulness ranking, position invariance or independent geographic confirmation
is established. Requested-only subset intervals (including Mantis/Idefics2) remain
unadjusted. Expanded Bonferroni intervals are approximate empirical sensitivity
checks, not exact simultaneous coverage. Different interval zero-crossings are
not an interaction test. No model/sample is selected by statistical significance.
