# V3 data and licensing

The eleven-model update retains the existing field-specific rights boundary.
Repository-authored code/documentation are Apache-2.0. The owner authorization of
2026-11-02 licenses only project-owned result, annotation, chart and added
wording/allocation contributions under CC BY 4.0, to the extent rights are held.
See `RESULTS_LICENSE_SCOPE.md` and the original v2 evidence matrix.

| Material/field | Applicable scope |
|---|---|
| CPU replay code and documentation | Existing Apache-2.0 |
| Project numerical summaries and annotations | Project-owned CC BY 4.0 scope |
| Questions, labels, class/source identities and pairing fields | Inherited M4/BEN terms and attribution |
| `answer`, `parsed_answer`, `raw_output`, equivalent generated content | Separate model/service output notices; no project blanket grant |
| Weights, images and upstream model implementations | Not bundled |
| License texts/third-party notices | Their own preserved terms |

The original five normalized model groups contain parsed answers only; six newer
groups also retain raw response text. Content is preserved without answer repair
or selection by correctness/significance. The package is not a complete raw-call
or image-route archive. Its output content is automatically generated research
observation, and a weight-license label does not independently clear output reuse.

`MODEL_OUTPUT_NOTICES.md` preserves the historical eight-model notice and adds
the v3 identities/access boundary. No common commercial/training reuse promise or
uniform prohibition is created for eleven heterogeneous configurations. Closed
service contractual conditions and available output rights must be assessed for
the relevant use; this release supplies no independent server snapshot.

The separate result attachment contains per-field `LICENSE_SCOPE.json` and the
relevant notices. No mixed ZIP is assigned one blanket license. Original imagery,
model weights, upstream implementations, client credential material, private paths
and manuscript author-placeholder PDFs are excluded. No new dataset split access
or official-test evaluation is granted.
