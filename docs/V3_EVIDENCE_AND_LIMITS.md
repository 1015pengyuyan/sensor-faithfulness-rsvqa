The current population is nine fixed open checkpoints plus two official-client
service configurations. Exact identities are in `configs/v3/models.json`.
GLM means GLM-4.1V-9B-Base. GLM-4.6V-Flash and the three historical v2-only
checkpoints are outside the current eleven-model normalized matrix.

- 195,618 immutable normalized scientific records; no replay rows.
- M4: 420 questions/420 target sources. BEN primary: 321/282; whole-source

## Completed post-hoc review supplement

The sealed 2026-11-19 supplement used local CPU processing of the same 195,618
saved records and existing source-multiplicity arrays. It introduced no inference
and no new source draws. Its completed work includes:

- Requested-only, nonrequested-only and text-only capability/answer coverage,
  with EarthMind marked not applicable; abstention/failure counts as wrong.
- All-C1 O/C/D contrasts without A0-correct filtering, original conditional
  contrasts, gold/class strata and BEN whole-source exclusion sensitivity.
- M4 common-question position effects and four-cell interactions, using direct
  paired differences; image order and prompt reference change together.
- Post-hoc multiplicity sensitivity using the archived source draws, with
  approximate rather than guaranteed simultaneous coverage.
- BEN position checks for Idefics2 (same-round paired data), Qwen2.5-VL-3B and
  Mantis (audited cross-run supplementary reuse). Requested SAR's Main slot is 2,
  so directional differences use actual slot 2 minus slot 1.

This supplement is a separate sealed evidence package, not reconstructed by the
v3 main-matrix command. Its endpoint counts are not independent sample sizes or
confirmatory test counts. No unarchived LLaVA bridge is authenticated for paired
BEN position inference.

## Outstanding experimental boundaries

No new matched-modality GPU experiment was run in the review supplement. Parent
scene/product/time/footprint independence and precision qualification remain
unresolved; candidate counts and call-budget scenarios are not completed
experiments or independent sample sizes. SAR display RGB values cannot silently
be treated as original radiometric bands or transformed again without evidence.

Fixed-donor behavioral contrasts cannot isolate sensor heterogeneity as a causal
mechanism or reveal which image the model internally used. Low reversal is not
faithfulness evidence, answered-only accuracy is not full-population capability,
and overlapping/nonoverlapping marginal intervals do not replace direct paired
differences. Source-cluster intervals do not resolve donor/parent-scene dependency
or closed-service generation variance. All zero, reverse and non-estimable
results remain in the complete matrix.
